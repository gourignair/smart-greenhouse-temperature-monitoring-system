# CAD Models
This folder contains the mechanical design files for the Smart Greenhouse Temperature Monitoring System.

## Files
### `greenhouse_assembly.f3z`
Complete Autodesk Fusion 360 assembly containing the greenhouse model and mechanical components.

### `roof_mount.stl`
3D-printable roof mount designed to support the automated window mechanism.

### `servo_cam.stl`
3D-printable servo cam used to actuate the greenhouse window.

### `greenhouse_2d_sketch.dxf`
2D engineering drawing used during the design process.

## Software
- Autodesk Fusion 360
- STL files suitable for 3D printing
- DXF engineering drawing

## Notes
The mechanical components were designed to integrate with the electronic system while remaining within the project size constraints.
